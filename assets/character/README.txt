Put Capri's character images in this folder (PNG, transparent background,
all the same size, 512x512 recommended, character facing RIGHT).

  <state>.png          one image for a state        e.g. idle.png
  <state>_<n>.png      animation frames from 1      e.g. idle_1.png, idle_2.png

States: idle, blink, happy, talking, thinking, searching, files, coding,
        alert, error, sleeping, standby, peek (optional)

Optional: rename animation.example.json to animation.json to set frame rates.
Then right-click Capri (or her tray icon) and choose "Reload assets".
See the project README for the full details.
